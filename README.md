# Tollbooth Simulation (C++)

Object-oriented C++ console program that models a toll booth, counting paying and non-paying cars and the total cash collected.

## Overview

The `tollBooth` class tracks:

- `totalCars`: every car that passes
- `totalMoney`: increases by 0.50 for each paying car

Methods: `payingCar()`, `nopayCar()`, and a display method that prints both totals.

## Build

Open `Labs3(Toolbooth).cbp` in Code::Blocks, or compile directly:

```bash
g++ main.cpp -o tollbooth
./tollbooth
```
